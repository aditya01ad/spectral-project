## Overview

This project implements and experiments with several core concepts in algebraic and spectral graph theory:

- **Zero Forcing**: A graph coloring propagation problem used to bound the minimum rank of a graph.
- **Spectral Properties**: Computation and comparison of graph eigenvalues (spectrum).
- **Cospectral Graphs**: Detection of non-isomorphic graphs that share identical spectra.
- **Minimum Rank**: Finding the minimum rank over all symmetric (or skew-symmetric) matrices associated with a graph.
- **DS Property**: Determining whether a graph is uniquely identified by its spectrum using the Godsil-McKay switching heuristic.

## Modules & Key Files

### Zero Forcing

**`cl_repo/repo1/zero_forcing.py`**  
Author: Thomas R. Cameron (11/23/2021)

Implements the zero-forcing propagation model and related parameters. A set of initially "colored" vertices propagates color to neighbors according to a forcing rule.

| Function | Description |
|---|---|
| `std_forcing_rule(g, colored, u)` | Standard forcing: a colored vertex forces its single uncolored neighbor |
| `psd_forcing_rule(g, colored, u)` | PSD (positive semidefinite) forcing rule |
| `skw_forcing_rule(g, colored, u)` | Skew-symmetric forcing rule |
| `closure(g, s, f)` | Computes the closure of a set `s` under forcing rule `f` |
| `zf_num_bf(g, f)` | Zero-forcing number via brute force |
| `zf_num_wf(g, f)` | Zero-forcing number via wavefront algorithm |
| `zf_poly(g, f)` | Zero-forcing polynomial |
| `prop_time(g, f)` | Propagation time of minimum zero-forcing sets |
| `thro_num(g, f)` | Throttling number |

### Minimum Rank

**`cl_repo/repo1/min_rank.py`**  
Author: Thomas R. Cameron (11/23/2021)

Computes the skew-symmetric minimum rank of a graph using symbolic algebra.

| Function | Description |
|---|---|
| `all_minors(mat, n, k)` | Enumerates all `k×k` minors of a symbolic matrix |
| `skew_min_rank(g)` | Computes the skew-symmetric minimum rank using Gröbner bases (SymPy) |

### DS/NDS Property Checking

**`py_codes/DS_NDS/prop_check/`**

Implements the Godsil-McKay (GM) switching heuristic to test whether a graph is *Determined by its Spectrum* (DS).

| File | Description |
|---|---|
| `ds_heuristic.py` | `find_gm_switching_partitions()`: finds valid (C, P) partitions; `perform_gm_switching()`: constructs cospectral mate; `check_ds_heuristic()`: main DS check |
| `graph_utils.py` | `get_spectrum()`: computes sorted eigenvalues of the adjacency matrix |
| `main.py` | Example driver — tests an example 7-node graph and prints DS/NDS conclusion |

**`py_codes/DS_NDS/find_ds/sage_ds/`**

SageMath scripts for finding spectral properties of complete graphs and searching for DS mates.

## Key Algorithms

1. **Zero-Forcing Propagation** — BFS-based coloring to compute zero-forcing number, polynomial, propagation time, and throttling number.
2. **Godsil-McKay Switching** — Constructs a cospectral non-isomorphic graph from a valid vertex partition (C, P), used to test the DS property.
3. **Spectral Computation** — Eigenvalue extraction via `numpy.linalg.eigvalsh` on the adjacency matrix.
4. **Graph Isomorphism Testing** — Uses NetworkX's built-in isomorphism check after GM switching.
5. **Gröbner Basis (SymPy)** — Algebraic method for determining skew-symmetric minimum rank.
6. **Wavefront Algorithm** — Efficient computation of the zero-forcing number by tracking closure pairs.
